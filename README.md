# Predicting Weather at the Jumbo Statue Using a CNN

## Authors

Angela Shen, Nanxi Liu, Jesus Naranjo 

## Project Overview

This project focuses on the development and evaluation of a deep learning model designed to predict weather conditions at a specific target location—the Jumbo statue on the Tufts University campus. The work includes training a convolutional neural network (CNN), diagnosing model behavior through spatial sensitivity analysis, and conducting an independent feature importance study using ablation experiments.

## Methods

  * **Model Architecture**: The team implemented a ResNet-inspired CNN featuring an initial convolutional layer followed by four residual blocks. The architecture utilizes global average pooling and two distinct output heads: one for continuous variable prediction and one for binary classification.
  * **Training & Optimization**: Models were trained using normalized data with an Adam optimizer, gradient clipping, and a CosineAnnealingLR scheduler.
  * **Weather Diagnosis**: To understand the model's decision-making process, saliency maps were generated by computing the gradient of the output with respect to the input. This identifies which geographic regions within the spatial input most heavily influence the local forecast.
  * **Ablation Study**: An independent study was performed by retraining the model with 19 different feature configurations to evaluate which combinations of weather variables possess the most predictive power.

## Dataset

  * **Timeframe**: The training and validation sets were drawn from weather data spanning 2018 to 2020, with 2021 reserved for final testing.
  * **Preprocessing**: The data handling pipeline included dropping missing (NA) values, chronological and random shuffling, and standard normalization.

## Evaluation Metrics

The model was compared against a standard "stub" baseline using the following metrics:

  * **RMSE (Root Mean Square Error)**: Applied to continuous variables including Temperature (TMP), Relative Humidity (RH), Wind components (UGRD/VGRD), and Wind Gusts.
  * **AUC (Area Under Curve)**: Used to evaluate binary precipitation forecasts (\> 2mm).

## Key Results

  * **Significant Gains**: The final CNN model outperformed the baseline significantly, achieving a **34% improvement** in Temperature and Relative Humidity RMSE and a **43% improvement** in binary precipitation AUC.
  * **Regional Context**: Saliency analysis demonstrated that the model relies on a broad regional context (approximately 80–90% of the input window) rather than just local target points, confirming its ability to capture large-scale weather patterns.
  * **Feature Sensitivity**: The ablation study found that while training on a single group of features resulted in poor performance, removing certain non-informative groups (such as precipitation for non-precipitation targets) could maintain or even slightly enhance the model's accuracy.
